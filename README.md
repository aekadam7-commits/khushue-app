# خُشوع — تطبيق إسلامي شامل

يعمل التطبيق **دون إنترنت** (المواقيت، الأذان، القبلة، المصحف، قراءة السور، البحث في القرآن، الأذكار، التقويم، رمز QR، الخطوط).
**الاستثناء الوحيد:** تلاوات القرآن الصوتية (تحتاج إنترنت).

## كيف يعمل
- `scripts/prepare-offline.js` يجهّز مجلد `www`: ينسخ ملفات التطبيق والأصوات، ويضمّن مكتبة `adhan` ومكتبة QR والخطوط من `node_modules`، ويجلب **نص القرآن كاملاً مع أرقام الصفحات** مرة واحدة وقت البناء إلى `www/data`.
- لا تحتاج رفع `www` إلى GitHub؛ يُولَّد تلقائياً.

## البناء (GitHub Actions)
تبويب **Actions ← Build APK ← Run workflow**، ثم حمّل `khushu.apk` من **Releases**.

## البناء محلياً
```
npm install
node scripts/prepare-offline.js
npx cap add android && npx cap sync android
```

## اختبار العمل دون إنترنت
ثبّت الـ APK، افتح التطبيق مرة واحدة، ثم فعّل **وضع الطيران** وجرّب: المواقيت، فتح سورة، المصحف بالصفحات، البحث في القرآن، رمز QR، معاينة صوت الأذان.

## المحتوى الإسلامي المحلي

يحتوي `content/islamic-library.json` على بيانات السيرة النبوية، وقصص الأنبياء، ومجموعة أذكار وأدعية، وأحداث تاريخية إسلامية وجزائرية وفلسطينية. أثناء البناء يحوّل `scripts/prepare-offline.js` هذا الملف إلى `www/data/islamic-library.js`، فيُضمّن المحتوى داخل التطبيق ويُتاح دون اتصال بالإنترنت. لا يعتمد تشغيل هذه الأقسام على تنزيل أول مرة من الشبكة.

تتضمن النسخة الحالية مجموعة تحريرية أولى وليست موسوعة نهائية شاملة؛ التواريخ المختلف فيها أو الأحداث المعاصرة موضحة داخل المحتوى، وينبغي مراجعة المراجع قبل توسيع قاعدة الأحداث.

## التغييرات في هذه النسخة

- إضافة قارئ بملء الشاشة للسيرة وقصص الأنبياء وحصن المسلم والأحداث التاريخية، مع السابق/التالي، تغيير حجم الخط، وحفظ موضع كل قسم محليًا.
- تضمين 20 فصلًا في السيرة، و25 قصة للأنبياء المذكورين في القرآن، و43 ذكرًا ودعاءً مختارًا، و47 بطاقة تاريخية (إسلامية وجزائرية وفلسطينية). هذه قاعدة موسعة أولية وليست موسوعة مكتملة نهائيًا.
- البحث في العناوين والنصوص والمراجع، وتقديم الأحداث التي يطابق تاريخها اليوم في أعلى قائمة الأحداث عندما تتوفر مطابقة موثقة.
- تحديث رابط مشاركة QR ليشير إلى مستودع `aekadam7-commits/khushue-app` واسم الملف `khushu.apk` الذي تنشئه مهمة البناء. لا يصبح رابط التنزيل صالحًا إلا بعد نشر إصدار فعلي يحتوي على هذا الملف.
- يظل سير عمل البناء يدويًا عبر `workflow_dispatch`، ولا يبدأ تلقائيًا.
