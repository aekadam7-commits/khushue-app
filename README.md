# خُشوع — مشروع توأم مطوّر

هذه نسخة تطوير مستقلة مبنية على ملفات المشروع المرفقة. احتُفظ بالوظائف الأصلية وأضيفت إليها:

- قسم المكتبة الإسلامية مع مجموعة أدعية وأذكار مصنفة، بحث، ونسخ النص.
- قسم السيرة النبوية بتسلسل زمني مختصر وبحث داخل الأحداث.
- توسيع فئات الأذكار وإضافة عداد تفاعلي لكل ذكر.
- تحسينات تصميم إضافية للمكتبة والسيرة مع دعم الوضع الليلي والتركيز بلوحة المفاتيح/ريموت التلفاز.
- سير عمل بناء APK ما زال يدويًا (`workflow_dispatch`) ولا يبدأ تلقائيًا.

## البناء

يتطلب Node.js 22 وJava 17. البناء يتم من GitHub Actions يدويًا عبر **Actions → Build APK → Run workflow**، أو باتباع خطوات Capacitor الواردة في سير العمل.

## تنبيه المحتوى

محتوى المكتبة والسيرة مجموعة تمهيدية مختارة وليست نسخة كاملة من كتاب «حصن المسلم» أو موسوعة سيرة موثقة تفصيليًا. بعض التواريخ والروايات التاريخية فيها اختلاف بين المصادر؛ ينبغي مراجعة مصادر الحديث والسيرة المعتمدة قبل اعتماد طبعة مرجعية نهائية.

## سلامة المشروع

لم تُحذف ملفات التطبيق الأصلية عمدًا. هذه نسخة ZIP مستقلة، ولا تقوم بتعديل مستودع GitHub الأصلي أو تشغيل عملية البناء تلقائيًا.
